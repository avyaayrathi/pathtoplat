# PathToPlat 🚀

PathToPlat is an AI-powered training coach designed to help competitive programmers progress from Bronze to Platinum by identifying algorithmic weaknesses and recommending targeted practice.

## Features
- Skill gap detection across algorithm topics
- Personalized problem roadmap
- Code complexity analysis
- USACO-focused training

## Motivation
While preparing for USACO Platinum, I realized students waste months practicing inefficiently. PathToPlat uses data-driven insights to accelerate algorithm learning.

## Tech Stack
- Backend: FastAPI (Python)
- Frontend: React / Next.js
- Database: PostgreSQL
- Analysis: Python ML models
